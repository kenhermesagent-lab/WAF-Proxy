## What this page is for
Tenants. Each site has its own hostnames, policies, users and console address, and its data is kept apart.

## Concepts
- **Default site** — the install itself; it serves the console you are using and cannot be disabled.
- **Console host** — the hostname that opens a site's console, for example `admin.example.com`.
- **Switch** — the topbar menu changes which site you are editing; every page follows it.

## First tasks
- Create a site before inviting the people who will run it.
- Set its console host, then invite an administrator scoped to that site.
