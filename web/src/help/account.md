## What this page is for
Your own sign-in: password, authenticator, trusted browsers, and the team on this site.

## Concepts
- **Second factor** — a code from an authenticator app, required in addition to the password.
- **Trusted browser** — one that may skip the code until the trust expires.
- **Recovery code** — single-use, and the only way back in if the authenticator is lost.

## First tasks
- Store the recovery codes somewhere other than this browser.
- Add a second administrator so a lost account is not a lockout.
