## What this page is for
The access gate: accounts that sign in before reaching a protected site, and the identity providers that can vouch for them.

## Concepts
- **Gate mode** — per hostname: `off`, a shared passphrase, gate accounts, or accounts plus a second factor.
- **Identity provider** — an external sign-in service that returns a verified header.
- **Session** — how long a gate sign-in lasts before it is asked again.

## First tasks
- Create a gate account, then switch one hostname's gate mode to accounts.
- Test in a private window before enabling it on a site other people use.
